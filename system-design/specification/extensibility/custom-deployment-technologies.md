# Custom Deployment Technology Support

Application suppliers may require a way to package and deploy applications using a deployment technology not defined by the Margo community.

The functionality is supported via [vendor-specific deployment technology specifications](../../make-a-contribution/deployment-technology-specifications#vendor-specific-deployment-technology-specifications) and may be used for collaboration between application and device suppliers to support deployment technologies not defined by the Margo community.

While custom deployment technology support is not interoperable by nature, a standardized approach ensures that such extensibility concerns do not break interoperability or conformance for other suppliers, that unknown deployment technologies are safely ignored, and that the Margo specification can evolve without breaking supplier-specific use cases.
