# Custom Deployment Technology Support

> **Note:** Need to update with links to the deployment technology specification guidelines documentation when it is available

Application suppliers may require a way to package and deploy applications using a deployment technology not defined by the Margo community.

The functionality is supported via vendor-specific deployment technology specifications and may be used for collaboration between application and device suppliers to support deployment technologies not defined by the Margo community.

While custom deployment technology support is not interoperable by nature, a standardized approach ensures such extensibility concerns do not break interoperability or conformance for other suppliers, that unknown deployment technologies are safely ignored, and that the Margo specification can evolve without breaking supplier-specific use cases.

The use of custom deployment technologies adds functionality not part of the Margo specification. It is expected suppliers collaborate in order to know what is available via the vendor-specific deployment technology specification. Margo does not maintain a listing of these vendor-specific deployment technology specification.
